## 撮り直し方

順序を変えると状態が揃わない。**この順で撮ること。**

1. `uv run python main.py --dry-run --dev-tools` で起動し、ブラウザを 1366×768 にする
2. `/monitor` → **01**
3. 「動作確認」→ **02** →「開始」→（dry-run では即失敗）→ **03**
4. 「DEV 全チェック」→ **04** → 試合開始 1 回目 → **05** → 2 回目 → **06**
5. 二度押しで試合終了 → **07** →「セッティングへ戻る」
6. `/main-hand` → **08** →「手動操縦」→ **09** →「半自動」
7. DEV 全チェック → 試合開始 → `/main-hand` → **10** → START →（即失敗）→ **11**
8. `/sub-hand` → START → **12** →「手動操縦」→ 電磁弁とポンプへ指令 → **13**
9. EMG STOP → **14** → Reset
10. サーバーを止める（再読み込みは不要。数秒で切断が画面に出る）→ **15**

**二度押し（04→05→06）は自動化しにくい。** 不感時間 400ms と自動解除 4 秒の間に 2 回目が要り、
ブラウザ自動化の往復はたいてい 4 秒を超える。武装したまま撮るには、**未武装のラベル
（`aria-label` が `試合を開始する`）に完全一致するときだけ**押す処理を 250ms 間隔で回す
—— 部分一致にすると武装後のボタン（`もう一度押して試合を開始する`）も掴んで試合が始まる。

**Before を撮るときは UI だけでなくサーバーも `main` へ戻す。** 理由は `../README.md`。
