## 1. サブハンドの試合シーケンス（未実装）

`sequences/sub_hand.py` は電磁弁とポンプだけの 4 段で、直動 2 軸とサーボ 3 軸を
一度も動かしていない（Issue #159）。段構成は決着済み。**未決は下の 2 点だけで、
どちらも位置定数の話**なので、段構成はこのまま書ける。

- **吸気ポンプ（`pump_vac`）を試合中回しっぱなしにしてよいか。** 回しっぱなしを前提に
  「吸着 / 解放は電磁弁だけで切り替える」と組んである。駄目ならサイクルごとに起動・停止する
  段が要り、`settle_s` 0.5s ぶんの待ちが毎回入る
- **箱の高さに段があるか。** あるなら `sub_lift.place` を段ごとに持つ

### 全体像

取るのは**棚から**（前後軸で水平に寄せる。下降しない）。置くのは**箱へ上から入れる**
（箱の上まで運んでから下降する）。

| 軸 | 役割 | 取る値 |
|---|---|---|
| `sub_rotate` | 姿勢。受け取り姿勢と搬送姿勢を切り替える | `receive` / `carry` |
| `sub_pitch` + `sub_offset` | 箱へ入れるための持ち方。**2 軸で 1 つ**として動かす | `open` / `close` |

### 段構成

| # | ステップ | 動かすもの | 確認 |
|---|---|---|---|
| 1 | 初期位置へ移動 | 弁 全閉 / 排気ポンプ 停止 / 吸気ポンプ 運転 / 回転 `receive` / 持ち方 `open` / 昇降 `top` / 前後 `retracted` | — |
| 2 | 棚のワークへ寄せる | 回転 `receive` → 前後 `receive` | 要 |
| 3 | 吸着 | 選ばれたパッドの弁だけ開 | — |
| 4 | 棚から浮かせる（約 10mm） | 昇降 `lifted` | 要 |
| 5 | 箱の上へ前後移動 | 前後 `place` | — |
| 6 | 搬送姿勢へ回転 | 回転 `carry` | — |
| 7 | 持ち方を閉じる | ピッチ + オフセット `close` | — |
| 8 | 箱へ下降 | 昇降 `place` | 要 |
| 9 | ワーク解放 | 弁 全閉 → 排気ポンプ 運転 → 停止 | 要 |
| 10 | 退避 | 昇降 `top` → 持ち方 `open` → 前後 `retracted` | — |
| 11 | 初期位置へ復帰 | 回転 `receive` | — |

繰り返しはステップ 2 へジャンプで回す。個数が決まればメインハンドと同じく書き下す。

### 崩してはいけない順序

- **前後を動かすのは棚・箱から浮いている高さのときだけ**
- **解放は弁を閉じてから正圧**（逆だと吸気経路に圧がかかる）
- **退避は昇降 → 持ち方 → 前後の順**（変えると箱の中で持ち方が開く）
- **`sub_pitch` と `sub_offset` は必ず同じ段で一緒に動かす**

### 位置定数に足すもの

| 軸 | 名前 | 満たすべき条件 |
|---|---|---|
| `sub_y_axis` | `retracted` / `receive` / `place` | −440 〜 2mm の内側。`receive` は前端スイッチの手前（作動点そのものは可動端インターロックが拒否する） |
| `sub_lift` | `top` / `lifted` / `place` | −152 〜 2mm の内側。`lifted` は棚から約 10mm 浮く高さ |
| `sub_rotate` | `receive` / `carry` | 左右ペア。逆回転側の `offset`（折り返し点）を実測してから |
| `sub_pitch` / `sub_offset` | `open` / `close` | 2 軸を同じ段で動かす |

## 2. リミットスイッチを NO から NC へ替える

極性は `firmware/servo/include/config.h` の `sensorActiveLow`（基板 #1 の SV1〜SV4 が
`true`）にあり、**yaml では切り替えられない**。替えるならファームの反転・書き込み・
`kFirmwareVersion` と `expected_firmware` の同時更新がセットになる。

## 3. メインハンド `y_axis` の左右位置ずれ

左右の M3508 が 106.7 と 211.4 で、互いに逆向きのトルクが出ている。軸の値は −14.0mm で
宣言範囲の外。この状態で零点合わせを回すと失敗する。**原因が分かるまでメインハンドは
動かさない。**

## 4. サーボ基板 #2（`0x50`〜`0x54`）が無応答

サブハンドのサーボ 5 スロットが全部この基板。基板 #1（`0x48`〜`0x4C`、可動端スイッチ
4 本を含む）は生きている。ハードウェア側の切り分け待ち。

## 5. 非常停止中のログが送信失敗で埋まる

モータ電源が落ちている間、3 バスとも送信が `Transmit buffer full` で失敗し、例外の
スタックトレースが数秒おきに出る（40 秒で 400 件超）。**動作には影響しない**
（イベントループが固まる不具合は別途修正済み）が、他のログが読めなくなる。1 行に畳む。
