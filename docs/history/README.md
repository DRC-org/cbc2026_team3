# docs/history —— 実機で観測された事象の記録

**ここは正ではない。** 「今どうなっているか」は次の 3 つを見ること。

| 見たいもの | 文書 |
|---|---|
| 構造・どこに何があるか | `docs/architecture.md` |
| なぜその実装なのか・触ってはならない規則 | `docs/invariants.md` |
| 点検とヘルスの現況 | `docs/checks_and_health.md` |

ここにあるのは**実機で観測された事象の記録**である。症状・実測値・数字を残してあるのは、
同じ壊れ方を繰り返さないため、そして次に測る人が同じ道を歩き直さないためである。
設計判断の論証はここには書かない（`docs/invariants.md` の仕事）。

- `incidents.md` —— 日付のある事象の時系列（**新しい日付が上**）
- `decisions.md` —— 日付が特定できない構造変更と、安全機構の穴の棚卸し

**完全な元テキスト**（各節の長い論証・コード引用・変異テストの表）は git 履歴に残っている。
`git log --follow docs/impl_plan.md` で辿れる。ここはその要約であって置き換えではない。
